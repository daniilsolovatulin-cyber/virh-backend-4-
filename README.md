# Вихрь — викторина с комнатами

Проект из двух частей:

- **`server/`** — бэкенд: Node.js + Express + SQLite + WebSocket.
  Аккаунты, профили с аватаром, комнаты, живой мультиплеер, генерация вопросов на сервере.
  Инструкция по запуску: `server/README.md`.

- **`public/`** — фронтенд: чистый HTML/CSS/JS, без сборки.
  Открывается статикой (можно через `npx serve public`, Live Server в VS Code, либо раздать самим Express-сервером).

## Быстрый старт

```bash
# 1. Бэкенд
cd server
npm install
cp .env.example .env
# впиши JWT_SECRET и GROQ_API_KEYS в .env
npm start
# сервер поднимется на http://localhost:3001

# 2. Фронтенд (в другом терминале)
cd ../public
npx serve -l 5173
# открой http://localhost:5173
```

По умолчанию `public/config.js` считает, что фронтенд открыт на `localhost` и стучится в бэкенд на `http://localhost:3001` — для локальной разработки ничего менять не нужно.

## Что изменилось по сравнению с исходным файлом

**Новое:**
- Регистрация и вход (username + пароль, хэшируется на сервере)
- Профиль: смена имени, загрузка своей фотографии как аватара, либо выбор эмодзи + цвета
- Комнаты с друзьями: создание комнаты с кодом, вход по коду, живой список игроков, синхронный показ вопросов всем участникам одновременно, общий счёт, таблица результатов
- Генерация вопросов перенесена на сервер для комнат (ключ Groq хранится в `.env` сервера, а не у каждого игрока в браузере)
- Визуальный редизайн: убраны яркие градиенты, "пухлые" тени и мультяшные иконки-пилюли; используется нейтральная палитра, табличные цифры для счёта, единая типографика — стилистика ближе к рабочему инструменту/табло, чем к развлекательному ИИ-шаблону

**Осталось как было:**
- Одиночная игра (Классика / Блиц / Правда-или-действие) по-прежнему работает без аккаунта, вводом своих ключей Groq API в настройках — это самый быстрый способ попробовать без разворачивания сервера
- Логика генерации вопросов и структура промптов не менялась

## Деплой в интернет

Смотри раздел «Деплой» в `server/README.md` — там про хостинг бэкенда (Railway/Render/VPS), постоянное хранилище для базы данных и аватаров, и переменные окружения.

Для фронтенда после деплоя бэкенда: открой `public/config.js` и пропиши туда адрес задеплоенного бэкенда вместо `http://localhost:3001`, затем залей папку `public/` на любой статический хостинг (Netlify, Vercel, GitHub Pages, тот же Railway static site).
